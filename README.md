# Hogona

Clickable prototype of Hogona (ಹೋಗೋಣ), a Bengaluru bus + metro trip app, following one rider, Ananya, on her commute from Marathahalli to her office in Indiranagar.

## Files

- `hogona-prototype3.html` – the current clickable prototype (opens at the site root on Netlify)
- `hogona-prototype.html` – v1, the first journey prototype with design notes per screen
- `hogona-prototype2.html` – v2, an early "Modern Vernacular" style exploration
- `illustrations/` – illustrations used by the prototype; files named by slot number replace the placeholder art
- `screenshots/` – every screen of the flow, numbered in order

## Run locally

Open `hogona-prototype3.html` in a browser. No build step.

## Deploy

Netlify: connect this repo, leave the build command empty. `netlify.toml` publishes the repo root and serves the prototype at `/`.
